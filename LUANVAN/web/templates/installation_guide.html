🐍 3. Cài đặt môi trường Python

3.1 Cài Python 3.10

Windows (PowerShell)
# Tải từ https://www.python.org/downloads/release/python-3100/ # Tích "Add Python to PATH" khi cài đặt python --version # Kết quả: Python 3.10.x
Ubuntu/Debian
sudo apt update && sudo apt install python3.10 python3.10-venv python3.10-dev -y

3.2 Tạo Virtual Environment

Windows
cd "d:/banduphong/LUANVAN (2) - Copy/LUANVAN (2) - Copy/LUANVAN/web" python -m venv venv310 venv310\Scripts\activate
Linux/Mac
cd /path/to/LUANVAN/web python3.10 -m venv venv310 source venv310/bin/activate

3.3 Cài đặt dependencies

pip
pip install -r requirements.txt # Nếu cần Emotional TTS (viXTTS) pip install -r requirements_vixtts.txt # Nếu lỗi torch, cài thủ công pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
💡 Luôn activate virtual environment trước khi chạy bất kỳ lệnh nào liên quan đến dự án.

🗄️ 4. Cơ sở dữ liệu MySQL

4.1 Cài đặt MySQL

Ubuntu
sudo apt install mysql-server -y sudo systemctl start mysql sudo mysql_secure_installation
ℹ️Windows: Dùng XAMPP (https://www.apachefriends.org/), khởi động MySQL từ Control Panel, quản lý qua phpMyAdmin tại http://localhost/phpmyadmin

4.2 Tạo Database

SQL
mysql -u root -p CREATE DATABASE tts_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; USE tts_system;

4.3 Tạo bảng chính

SQL — Bảng users
CREATE TABLE users ( id INT AUTO_INCREMENT PRIMARY KEY, username VARCHAR(50) UNIQUE NOT NULL, email VARCHAR(100) UNIQUE NOT NULL, full_name VARCHAR(100), password_hash VARCHAR(256), role ENUM('user', 'admin') DEFAULT 'user', status ENUM('active', 'suspended') DEFAULT 'active', subscription_plan VARCHAR(20) DEFAULT 'free', characters_used INT DEFAULT 0, characters_limit INT DEFAULT 5000, subscription_expires DATETIME, google_id VARCHAR(100), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );
SQL — Bảng conversions
CREATE TABLE conversions ( id VARCHAR(36) PRIMARY KEY, user_id INT NOT NULL, text_input TEXT, voice_name VARCHAR(100), emotion VARCHAR(50) DEFAULT 'neutral', audio_file VARCHAR(500), characters_count INT DEFAULT 0, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE );
SQL — Bảng custom_voices
CREATE TABLE custom_voices ( id INT AUTO_INCREMENT PRIMARY KEY, user_id INT NOT NULL, voice_name VARCHAR(100) NOT NULL, display_name VARCHAR(100), description TEXT, model_path VARCHAR(500), reference_audio VARCHAR(500), status ENUM('training', 'ready', 'failed') DEFAULT 'training', created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE );
SQL — Bảng payments
CREATE TABLE payments ( id INT AUTO_INCREMENT PRIMARY KEY, user_id INT NOT NULL, plan_id VARCHAR(50) NOT NULL, amount DECIMAL(12,0) DEFAULT 0, transaction_id VARCHAR(100), status ENUM('pending', 'completed', 'failed') DEFAULT 'pending', payment_method VARCHAR(50) DEFAULT 'sepay', created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, completed_at DATETIME, FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE );

⚙️ 5. Cấu hình file môi trường

▶️ 7. Chạy server local

Windows
cd "d:/banduphong/LUANVAN (2) - Copy/LUANVAN (2) - Copy/LUANVAN/web" venv310\Scripts\activate python app.py
Linux/Mac

Khi khởi động thành công sẽ thấy:

🚀 8. Deploy lên Railway

1
Tạo tài khoản Railway tại railway.app → New Project → Deploy from GitHub
2
Connect GitHub repository chứa code
3
Thêm MySQL: New → Database → MySQL
4
Cấu hình Variables (tab Settings): DB_HOST, DB_PASSWORD, FLASK_SECRET_KEY, GOOGLE_CLIENT_ID...
5
Railway tự build và deploy — xem logs trong tab Deploy

Các file cấu hình Railway (đã có sẵn):

Procfile
web: gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --timeout 120
runtime.txt
python-3.10.14
⚠️Emotional TTS yêu cầu RAM ~4 GB. Railway free tier có thể không đủ — xem xét nâng cấp plan hoặc tắt Emotional TTS khi deploy.

🔐 9. Cấu hình Google OAuth

1
Vào console.cloud.google.com → Tạo project mới
2
APIs & Services → Credentials → Create OAuth 2.0 Client IDs
3
Application type: Web application
4
Thêm Authorized redirect URIs:
http://localhost:5000/auth/google/callback (local)
https://your-app.railway.app/auth/google/callback (production)
5
Copy Client ID và Client Secret vào .env.local

💰 10. Cấu hình SePay thanh toán

1
Đăng ký tại sepay.vn → Thêm tài khoản ngân hàng
2
Lấy API Token từ dashboard SePay
3
Điền vào .env.local: SEPAY_TOKEN, SEPAY_ACCOUNT_NUMBER, BANK_NAME...
4
Webhook endpoint: POST /api/payment/webhook/sepay — cần URL HTTPS công khai

🔧 12. Khắc phục sự cố

LỗiGiải pháp
ModuleNotFoundError: flaskKiểm tra virtual env đã activate chưa, chạy pip install -r requirements.txt
pymysql.err.OperationalErrorKiểm tra MySQL đang chạy, thông tin DB trong .env.local đúng chưa
Port 5000 đã dùng (Windows)netstat -ano | findstr :5000 → taskkill /PID <PID> /F
CUDA out of memoryĐổi sang CPU: device = "cpu" trong emotional_tts_vixtts.py
Lỗi UTF-8 WindowsĐã xử lý trong app.py — kiểm tra Python console encoding
Emotional TTS load chậmBình thường — lần đầu mất 30–60 giây load model vào RAM

✅ Checklist triển khai

  • Python 3.10 đã cài và kiểm tra python --version
  • Virtual environment tạo và activate thành công
  • pip install -r requirements.txt không có lỗi
  • MySQL đang chạy, database tts_system đã tạo
  • Bảng users, conversions, custom_voices, payments đã tạo
  • File .env.local đã cấu hình đầy đủ
  • Thư mục uploads/ và audio_outputs/ đã tạo
  • File giọng tham chiếu (base_voice.wav, v.v.) đã có
  • (Tuỳ chọn) viXTTS model đã tải về thư mục vixtts_model/
  • Server khởi động thành công tại http://127.0.0.1:5000
  • Đăng ký tài khoản và đăng nhập hoạt động
  • TTS cơ bản chuyển đổi thành công
  • (Tuỳ chọn) Google OAuth đã test thành công
